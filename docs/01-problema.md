# Problema

## Contexto

Docentes y alumnos de la Universidad del CEMA pueden necesitar crear presentaciones academicas de forma rapida, consistente y alineada con una identidad institucional.

## Problema principal

Crear presentaciones de calidad requiere organizar materiales, seleccionar un formato adecuado, mantener coherencia visual y adaptar el contenido al perfil de uso. Sin una herramienta especifica, este proceso puede volverse manual, disperso y poco consistente.

## Personas, areas o usuarios afectados

- Docentes que preparan clases, seminarios o actividades.
- Alumnos que preparan exposiciones, entregas o defensas.

## Situacion actual

Se solicito un aplicativo capaz de cargar informacion, previsualizar una presentacion y descargar un archivo PowerPoint.

## Evidencia disponible

- Solicitud funcional realizada por el usuario en este repositorio.
- Pagina oficial de material institucional UCEMA: https://ucema.edu.ar/la-ucema/logos

## Preguntas pendientes

- Que sistemas o criterios internos de UCEMA deberian usarse para validar usuarios?
- Que nivel de automatizacion se espera para procesar archivos, enlaces o audios?
- Que plantillas oficiales de UCEMA estan autorizadas para integrarse?
